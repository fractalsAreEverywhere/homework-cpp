# ДЗ 3 — SparseMatrix

Реализованы плотная матрица на плоском vector и разреженная на
`std::map<std::pair<int, int>, double>`. В разреженной матрице хранятся только
ненулевые элементы. Виртуальный `mul` поддерживает все четыре сочетания типов.

## Файлы

- `include/matrix.h` — абстрактный класс Matrix.
- `src/matrix.cpp` — общий метод print.
- `include/dense_matrix.h` — поля и объявления методов DenseMatrix.
- `src/dense_matrix.cpp` — тела методов DenseMatrix.
- `include/sparse_matrix.h` — поля и объявления методов SparseMatrix.
- `src/sparse_matrix.cpp` — тела методов SparseMatrix.
- `src/main.cpp` — одинаковый ручной пример для четырёх сочетаний.
- `tests/test_sparse.cpp` — проверки корректности с отдельным выводом по группам.
- `bench/bench_sparse.cpp` — измерения на одинаковых данных при разных плотностях.
- `bench/results.csv` и `bench/RESULTS.md` — реальные измерения и их разбор.
- `РАЗБОР.md` — объяснение реализации и вопросы для защиты.
- `AI_USE.md` — происхождение кода и текст для будущего коммита.

ДЗ 3 использует отдельную копию основы ДЗ 2. В неё добавлены const-методы,
проверка индексов и смешанное умножение. В ДЗ 2 также разделены заголовки Matrix и DenseMatrix; алгоритмы сохранены.

## Visual Studio

Открыть папку `hw3`, выбрать конфигурацию `debug-asan` и цель `hw3_demo`
для примеров или `hw3_tests` для проверок.
Для бенчмарка выбрать конфигурацию `release` и цель `hw3_bench`.

## В терминале разработчика Visual Studio

Команды выполняются из папки hw3. Нужны MSVC с AddressSanitizer, CMake 3.21+
и Ninja.

```powershell
cmake --preset debug-asan
cmake --build --preset debug-asan
ctest --preset debug-asan -V
.\out\debug-asan\hw3_demo.exe
```

Debug включает ASan как для кода матриц, так и для кода проверок.
При сборке MSVC необходимые DLL AddressSanitizer автоматически копируются
рядом с exe. Поэтому тесты можно запускать и из обычного терминала Windows.
Проверки используют исключения вместо assert и не отключаются в Release.
Ожидаемый вывод: все группы проверок passed; пропущенных тестов больше нет.

```powershell
cmake --preset release
cmake --build --preset release
.\out\release\hw3_bench.exe bench/results.csv
```

Бенчмарк требует Release; в этой конфигурации MSVC использует /O2,
санитайзер отключён. Бенчмарк не собирается при обычной сборке Debug.
Путь CSV необязателен: без аргумента программа только печатает результаты.
В консоли показана таблица со временем в миллисекундах; в CSV время остаётся
в секундах. `Dense/Sparse` — отношение времени Dense к Sparse:
значение больше 1 означает преимущество Sparse.

Из корня репозитория также доступны цели hw3_demo, hw3_tests, hw3_bench.
Для тестов включить HW3_ENABLE_ASAN=ON и Debug. Для бенчмарка — Release
и HW3_ENABLE_ASAN=OFF.

## Что проверено

- Хранение, перезапись, удаление нулём, отсутствие вставки при чтении.
- Переводы в обе стороны, сохранение размеров и значений.
- Ручное прямоугольное умножение, дробные и отрицательные значения.
- Единичная/нулевая матрица с обеих сторон, пустые размеры.
- Сокращение ненулевых вкладов до нуля без хранения нулевой записи.
- Несовместимые размеры во всех сочетаниях, недопустимые индексы и размеры.
- 60 случайных пар матриц разных размеров и плотностей:
  четыре сочетания сравниваются с наивным плотным i-j-k из ДЗ 2.
- Бенчмарк дополнительно сверяет Dense и Sparse перед каждым набором замеров.

Поддерживаются неотрицательные размеры и допустимые индексы.
Матрицы предназначены для конечных чисел double; отдельная семантика
NaN/бесконечности здесь не рассматривается.
